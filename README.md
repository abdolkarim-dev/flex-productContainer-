## 📌 About The Project

This project is a **simple product container layout** built with **HTML and CSS**, using **Flexbox** for layout structure.  
It demonstrates how to align and organize product items in a clean and responsive way without any frameworks.

This project is suitable for **beginners**, **practice purposes**, or as a foundation for **e-commerce layouts**.

---

## ✨ Features

- 📦 Product container layout using Flexbox
- 📱 Responsive structure
- 🎨 Clean and simple UI
- ⚡ Lightweight (no frameworks)
- ♻️ Easy to read and customize code
